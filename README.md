# Gayathri Ande — Developer Portfolio

An interactive little expedition through an abandoned-but-not-forgotten Earth. Follow the rover through its workspace, data yard, old terminals, project discoveries, and a rooftop at first light.

I built this portfolio to bring together the things I enjoy most: full-stack development, AI/ML, and thoughtful user experiences.

## Take a look around

- **One connected journey:** eight places to explore, from the opening desert to the final rooftop.
- **A curious rover:** scroll to send it exploring; hover or focus to make it blink, then click for a random message and a tiny mechanical chirp.
- **Real work, not skill meters:** experience, projects, tools, and education are part of the world.
- **Made for different screens:** the layout adapts to desktop and mobile, and respects reduced-motion preferences.

The rover, landscapes, terminals, and found objects are original CSS and SVG illustrations. The voice uses browser speech synthesis when available, so the exact sound depends on the device and browser.

## Run it locally

You’ll need Node.js and npm.

```bash
npm install
npm run dev
```

Vite prints a local URL in the terminal. Open it in a browser to start exploring.

Create a production build with:

```bash
npm run build
```

## Deploy with Vercel

1. Push this project to a GitHub repository.
2. In Vercel, import the repository.
3. Keep the detected **Vite** framework and default build settings.
4. Deploy.

The contact form works without extra configuration by opening an email draft. To receive messages through Formspree instead, create a form, add `VITE_FORMSPREE_ID` to the project’s Vercel environment variables, and redeploy.
